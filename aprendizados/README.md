# Aprendizados

Notas sobre bibliotecas, ferramentas e erros que custaram caro. Não são regras: são o porquê e o como, para consultar quando o assunto aparece.

## Quando uma nota entra aqui

- Algo deu errado, ou quase, e a causa não era óbvia.
- A lição vale fora do projeto onde aconteceu.
- Ainda não é forte ou geral o bastante para ser regra numa skill. Quando se repetir, promove-se.

## Formato

Nome: `AAAA-MM-DD-assunto.md`, com a data em que a nota entrou aqui. Uma nota por assunto. Dentro, cada lição segue este modelo:

```
## Título curto do que aprender

**O que aconteceu:** o sintoma, sem nomes de pessoas nem de empresas.
**Por que:** a causa medida.
**Como fazer:** a regra prática, com um exemplo de código se ajudar.
**Versão:** a versão da biblioteca, quando a lição depende dela.
```
