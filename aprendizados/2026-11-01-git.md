# Git

## Um clone novo usa a identidade global

**O que aconteceu:** um clone de teste fazia os commits com o nome verdadeiro e o e-mail pessoal da configuração global. Num repositório público, isso fica em cada commit para sempre.
**Como fazer:** depois de clonar, `git config --local user.email <id>+<conta>@users.noreply.github.com` e um `user.name` público. O portão `identidade.py` (em `modelos/git/portoes/`) recusa outro e-mail.

## `git commit -- <caminhos>` perde a marca de executável no Windows

**O que aconteceu:** um hook do git preparado com `--chmod=+x` foi gravado como `100644`; num clone Linux ou no CI, um hook sem a marca é ignorado sem aviso.
**Por que:** com `core.filemode=false`, o commit por caminho relê os arquivos do disco e esquece o modo preparado.
**Como fazer:** `git add -- <f>`, `git add --chmod=+x -- <f>`, confira o `git diff --cached` e `git commit -i -F msg -- <f>` (o `-i` usa o índice). Confirme com `git ls-tree HEAD <f>`.

## `git checkout -- <arquivo>` apaga o que não foi commitado

**O que aconteceu:** um script repunha um arquivo com `git checkout` depois de cada mutação, e apagou uma correção ainda por commitar.
**Como fazer:** para repor um arquivo mexido de propósito, guarde os bytes antes e escreva-os de volta num `finally`. O git só conhece o que foi commitado.

## Os objetos do git são só de leitura no Windows

**O que aconteceu:** `shutil.rmtree` de um repositório temporário falhou com "Acesso negado" num arquivo de `.git/objects`.
**Como fazer:** passe um tratador que tira o atributo e tenta de novo: `os.chmod(caminho, stat.S_IWRITE)` e `funcao(caminho)` (`onerror` até o Python 3.11, `onexc` a partir do 3.12).

## `grep -P` não funciona no Git Bash com a localidade padrão

**O que aconteceu:** um script de commits usava `grep -P` para recusar mensagens com acentos; no Git Bash deu "-P supports only unibyte and UTF-8 locales", e a verificação não rodou, calada.
**Como fazer:** use `LC_ALL=C grep '[^ -~]'` para achar caracteres fora do ASCII, e confira depois sobre o resultado (`git log --format=%B`).
